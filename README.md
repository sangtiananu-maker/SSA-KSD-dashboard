# Pharma Alliance (PAC) - Executive Sales & Incentive Dashboard (August 2026)

ระบบเว็บแดชบอร์ดสำหรับผู้บริหารและทีมฝ่ายขาย/การตลาด (Sales & Marketing) ของบริษัท **Pharma Alliance (PAC)** เชื่อมโยงข้อมูลยอดขายครบทุกมิติ:
1. **ยอดขายหน้าร้านขายยาใสสะอาด (SSA Pharmacy Sell-Out)** 6 สาขา
2. **โหมดตรวจเยี่ยมสาขา (Store Visit Deep-Dive)** พร้อม Top 10 Growth / Decline และแจ้งเตือนของขาด (Zero-Sales Alert)
3. **ตารางเมทริกซ์ตรวจโอกาสสินค้ากลยุทธ์ (Strategic White-Space Matrix)** 
4. **ระบบวิเคราะห์ค่าเชียร์สนับสนุนร้านยา SSA 17 เดือน (Incentive Analytics)** พร้อมปุ่มสลับ **รายเดือน / YTD / รายปี / YoY**
5. **การกระจายสินค้าผ่าน KSD Distributor (Sell-In)** และผลงานพนักงานขาย KSD
6. **รายการสินค้ากลยุทธ์ PAC Catalog 2026** (ปรับปรุง Glucovia: Sitagliptin)
7. **พจนานุกรมและตารางเทียบชื่อยา 3 ภาษา (ลาว ➔ ไทย ➔ อังกฤษ)** พร้อมค้นหาและส่งออก Excel
8. **หน้าต่างนำเข้าข้อมูลเดือนใหม่ (Import Data Modal)** สำหรับอัปเดตข้อมูลเดือนถัดไปได้ง่ายดายผ่านหน้าเว็บ

### ขั้นตอนที่ 2: อัปโหลดชุดไฟล์ขึ้นไป
1. ในหน้า Repository ที่เพิ่งสร้าง ให้คลิกที่ **"uploading an existing file"** (หรือลากไฟล์ใส่ผ่าน GitHub Desktop)

   - `index.html` (แดชบอร์ดชุดเดิม)
   - `styles.css`
   - `app.js`
   - `powerbi.html` (แดชบอร์ดโหมด Power BI)

   - `powerbi_app.js`

   - `assets/` (โลโก้ PAC, KSD, SSA)
   - `PowerBI_DataModel/` (โมเดลข้อมูลสำหรับ Power BI Desktop)
   - `.nojekyll`

3. คลิกปุ่ม **"Commit changes"** สีเขียวด้านล่าง

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ไปที่เมนู **Settings** (รูปเฟือง) ด้านบนของ Repository

## 📖 สรุปฟังก์ชันเด่นในระบบ

### 1. ระบบวิเคราะห์ค่าเชียร์ 17 เดือน (Incentive Analytics)
- รวบรวมข้อมูลค่าเชียร์จริงตั้งแต่ **เม.ย. 2025 ถึง ส.ค. 2026** ครบถ้วนถูกต้อง 100%
- มีปุ่มสลับรูปแบบรายงาน:
  - **รายเดือน (Monthly)**: ดูรายละเอียดสินค้าและแยกรายสาขาของเดือนนั้นๆ
  - **สะสมต้นปี (YTD)**: ยอดสะสมตั้งแต่เดือน ม.ค. ถึงเดือนที่เลือก
  - **รายปี (Yearly)**: ยอดรวมตลอดทั้งปี
  - **เปรียบเทียบปี (YoY)**: เปรียบเทียบเดือนเดียวกันระหว่างปี 2026 vs 2025 พร้อมเปอร์เซ็นต์เติบโต (% Growth)
- สลับดูกราฟแนวโน้มได้ทั้งแบบ **"ยอดเงิน (บาท)"** และ **"จำนวนชิ้น"**

### 2. โหมดตรวจเยี่ยมสาขา (Store Visit Mode)
- **เมื่อลงพื้นที่ตรวจหน้าร้าน SSA**: เลือกสาขาที่ต้องการตรวจ (SSA1 ถึง SSA7) เพื่อดูบทวิเคราะห์สุขภาพของสาขานั้น
- **Top 10 Growth**: สินค้าที่มียอดขายเติบโตขึ้นสูงสุดเมื่อเทียบกับเดือนก่อนหน้า (ก.ค. ➔ ส.ค. 26)
- **Top 10 Decline**: สินค้าที่ยอดขายลดลงมากที่สุด เพื่อตรวจเช็คปัญหาหน้าร้านทันที
- **Zero-Sales Alert**: แจ้งเตือนสินค้าค่าเชียร์ที่เคยขายได้แต่เดือนนี้ยอดเป็น 0 ชิ้น
- **พิมพ์รายงาน One-Pager**: กดปุ่ม "พิมพ์ One-Pager" ที่มุมขวาบนเพื่อปริ้นต์เอกสารสรุป 1 แผ่น ถือเข้าไปคุยกับหน้าร้าน

### 3. ตารางโอกาสสินค้ากลยุทธ์ (Strategic White-Space Matrix)
- ตารางเปรียบเทียบการกระจายสินค้าของ 6 สาขาร้านยา SSA
- ช่องเขียว = สาขานี้มียอดขายแล้ว | ช่องแดง = สาขานี้ยังไม่เคยวางจำหน่าย เพื่อให้เซลส์ไปเปิดออเดอร์ใหม่

### 4. ตารางเทียบชื่อยา 3 ภาษา (Lao-Thai-English Dictionary)
- ตารางค้นหายาที่มีทั้งชื่อภาษาลาว (SSA), คำอ่านถอดเสียงภาษาไทย, และชื่อสากล (KSD/PAC) (กรองสินค้าของแถม Free ออกแล้ว)
- ค้นหาแบบ Real-time และกดส่งออกเป็น Excel ได้ทันที

### 5. นำเข้าข้อมูลเดือนใหม่ (Import Data Interface)
- กดปุ่ม **"นำเข้าข้อมูลเดือนใหม่"** ที่แถบเมนูด้านบน เพื่อลากไฟล์ Excel/CSV ของเดือนถัดไปมาอัปเดตผ่านหน้าเว็บได้ทันที
